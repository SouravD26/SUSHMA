# SUSHMA Beauty & Hair Saloon

Website for Sushma Beauty & Hair Saloon, Narendrapur. Built with React, Vite, React Router and Framer Motion.

## Run locally

```bash
npm install
npm run dev
```

## Deploy on Vercel

Import this repo in Vercel. The settings are already in `vercel.json` (Vite, `dist` output, page routes rewrite to `index.html`).

Salon details and services live in `src/data.js`.
